## 1.1 引言 (pp.1–2)

**机器学习**:致力于研究如何通过计算的手段,利用经验来改善系统自身的性能。

- 在计算机系统中,"经验"通常以**数据**形式存在 → 机器学习的主要内容:在计算机上从数据中产生**模型** (model) 的算法,即**学习算法** (learning algorithm)。
- 类比:计算机科学是研究"算法"的学问,机器学习是研究"学习算法"的学问。
- 学习流程:学习算法 + 经验数据 → 模型 → 面对新情况时提供判断。

**Mitchell (1997) 形式化定义**(页边注):

> 假设用 $P$ 评估计算机程序在某任务类 $T$ 上的性能,若一个程序通过利用经验 $E$ 在 $T$ 中的任务上获得了性能改善,则称**关于 $T$ 和 $P$,该程序对 $E$ 进行了学习**。

即学习 = 利用经验 E 在任务 T 上提升性能度量 P。三要素:任务、性能度量、经验。

> 注:本书用"模型"泛指从数据中学得的结果;有文献用"模型"指全局性结果(如整棵决策树),"模式"指局部性结果(如一条规则)。

## 1.2 基本术语 (pp.2–4)

### 数据与样本

- **数据集** (data set):一组记录的集合,每条记录是关于一个事件或对象的描述,称为一个**示例** (instance) 或**样本** (sample)。(注意:"样本"也可指整个数据集,视作对样本空间的一次采样,通过上下文判断)
- **属性** (attribute) / **特征** (feature):反映对象某方面表现或性质的事项,如"色泽""根蒂""敲声";**属性值** (attribute value):属性上的取值,如"青绿""乌黑"。
  - ⚠️ 易错:样本是属性的取值组合(一条记录),**不是**"分为特征和属性值";属性是维度,属性值是维度上的取值。
- **属性空间** / **样本空间** (sample space) / **输入空间**:属性张成的空间(如色泽、根蒂、敲声为坐标轴的三维空间)。
- **特征向量** (feature vector):示例在样本空间中对应的坐标向量。
- 数据集 $D=\{\mathbf{x}_1,\mathbf{x}_2,\dots,\mathbf{x}_m\}$,每个示例 $\mathbf{x}_i=(x_{i1};x_{i2};\dots;x_{id})$ 是 $d$ 维样本空间 $\mathcal{X}$ 中的向量,即 $\mathbf{x}_i\in\mathcal{X}$,其中 $x_{ij}$ 是 $\mathbf{x}_i$ 在第 $j$ 个属性上的取值;$d$ 称为样本的**维数** (dimensionality)。

### 学习过程

- **学习** (learning) / **训练** (training):从数据中学得模型的过程,通过执行某个学习算法完成。
- **训练数据** (training data)→ **训练样本** (training sample)→ **训练集** (training set)。
- 学得模型对应了数据中某种潜在规律,故亦称**假设** (hypothesis);潜在规律自身称**真相** / **真实** (ground-truth)。学习过程 = 找出或逼近真相。
- **学习器** (learner):模型的别名,可看作学习算法在给定数据和参数空间上的实例化。

### 预测任务:标记、样例与映射

- **标记** (label):示例结果的信息,如"好瓜";拥有标记的示例称**样例** (example),记 $(\mathbf{x}_i,y_i)$,其中 $y_i\in\mathcal{Y}$ 是 $\mathbf{x}_i$ 的标记,$\mathcal{Y}$ 是所有标记的集合,称**标记空间** / **输出空间**。
- 预测任务:对训练集 $\{(\mathbf{x}_1,y_1),\dots,(\mathbf{x}_m,y_m)\}$ 学习,建立从输入空间 $\mathcal{X}$ 到输出空间 $\mathcal{Y}$ 的映射 $f:\mathcal{X}\to\mathcal{Y}$。
  - **分类** (classification):预测离散值。二分类: $\mathcal{Y}=\{-1,+1\}$ 或 $\{0,1\}$(两类称正类/反类);多分类: $|\mathcal{Y}|>2$。
  - **回归** (regression):预测连续值,$\mathcal{Y}=\mathbb{R}$。
- **测试** (testing):学得模型后用它进行预测的过程;被预测的样本称**测试样本** / **测试例**,对测试例 $\mathbf{x}$ 得到预测标记 $\hat{y}=f(\mathbf{x})$。

### 聚类与学习任务划分

- **聚类** (clustering):把训练集中的样本分成若干组,每组称一个**簇** (cluster);簇可能对应潜在概念划分(如"浅色瓜""本地瓜"),但这些概念事先未知,训练样本通常无标记。
- 按训练数据是否拥有标记信息,学习任务分两大类:
  - **监督学习** (supervised learning):分类、回归为代表;
  - **无监督学习** (unsupervised learning):聚类为代表。

### 泛化能力

- **泛化** (generalization) 能力:学得模型适用于**新样本**("未见示例")的能力。机器学习的目标是泛化,而非仅在训练样本上工作得好。
- 现实任务中样本空间规模通常很大(如 20 个属性、每个属性 10 种取值,规模达 $10^{20}$),训练集只是其很小的采样,却要反映样本空间特性。
- 通常假设全体样本服从某个未知**分布** (distribution) $\mathcal{D}$,每个样本**独立同分布** (i.i.d.) 地从 $\mathcal{D}$ 采样获得。一般而言,训练样本越多,关于 $\mathcal{D}$ 的信息越多,越可能学到强泛化模型。

## 1.3 假设空间 (pp.4–6)

### 归纳与演绎

- **归纳** (induction):从特殊到一般的"泛化"过程(从具体事实归结出一般规律);**演绎** (deduction):从一般到特殊的"特化"过程(从原理推演出具体状况)。
- "从样例中学习"是归纳过程,故亦称**归纳学习** (inductive learning):
  - 广义:大体相当于从样例中学习;
  - 狭义:要求从训练数据中学得概念 (concept),称**概念学习** / 概念形成。目前研究应用较少(要学得泛化好且语义明确的概念太难,现实多用"黑箱"模型),但对理解机器学习基础思想有帮助。
- 概念学习最基本的是**布尔概念学习**:学形如 $(\text{色泽}=?)\wedge(\text{根蒂}=?)\wedge(\text{敲声}=?)$ 的布尔表达式,把"?"确定下来。

### 假设空间与规模

- 学习过程 = 在所有假设组成的空间(假设的表示一旦确定,假设空间及其规模就确定)中搜索,目标是找到与训练集**匹配**(能对训练集中样本做出正确判断)的假设。
- 假设的三种成分:
  - 具体取值:如色泽 = 青绿/乌黑/浅白;
  - 通配符 `*`:该属性取什么值都合适,如"(色泽=*)∧(根蒂=蜷缩)∧(敲声=浊响)";
  - 空假设 $\varnothing$:好瓜概念根本不成立(没有好瓜)。
- 假设空间规模:色泽、根蒂、敲声各有 3 种取值,加上通配符 `*` 各 4 种可能,即 $4\times4\times4$;再加空假设:
  $$|\mathcal{H}| = 4\times4\times4 + 1 = 65$$
  ⚠️ 初版(本 PDF)误写为"3、2、2 种取值,规模 37",官方勘误为 65。
- 搜索策略:自顶向下(一般→特殊)或自底向上(特殊→一般);搜索中不断删除**与正例不一致**的假设和(或)**与反例一致**的假设。⚠️ 本 PDF 初版正文"色泽有 3 种取值"与表 1.1 中仅出现 2 种(青绿、乌黑)并不矛盾:取值数是属性的**全部可能取值**(浅白在全书中也出现)。

### 版本空间 (version space)

- 现实问题假设空间很大,但训练集有限 → 可能有**多个假设与训练集一致**,这些假设的集合称**版本空间**。
- 图 1.2 中表 1.1 对应的版本空间含 3 个假设(按官方勘误,⚠️ 本 PDF 图中两处"清脆"应为"浊响"):

| | 假设 | 说明 |
|---|---|---|
| ① | 好瓜 ⟺ (色泽=*) ∧ (根蒂=蜷缩) ∧ (敲声=*) | 最一般,只信根蒂 |
| ② | 好瓜 ⟺ (色泽=*) ∧ (根蒂=*) ∧ (敲声=浊响) | 只信敲声 |
| ③ | 好瓜 ⟺ (色泽=*) ∧ (根蒂=蜷缩) ∧ (敲声=浊响) | ① 与 ② 的交集,最特殊 |

- 版本空间推导思路:先保留与正例(1、2)一致的假设——好瓜的公共属性是"根蒂=蜷缩、敲声=浊响",色泽只能取 `*`(否则另一个正例被误判);再删除把反例(3、4)判为好瓜的假设。

### 概念澄清:假设空间 vs 版本空间(2026-08-08)

<span style="color:#c0392b">**❌ 常见误解**</span>

1. "假设空间是瓜的可能组合"——不对:27 个具体瓜是**属性空间的样本**;假设空间是**规则的集合**(每个假设 = 一条"好瓜 ⟺ 条件"的规则,圈出一个好瓜集合)。
2. "版本空间是模型认为是好瓜的假设"——时间线错位:此时**模型还没有产生**;版本空间是"与训练集一致的所有规则",正是候选太多才需要归纳偏好(1.4 节)来选。

<span style="color:#27ae60">**✅ 正确理解**</span>

- **假设空间** = 所有可能的判别规则(西瓜问题 65 条:64 个非空条件 + 空假设 ∅);
- **版本空间** = 假设空间中**与训练集一致**(能对每个训练样本判断正确)的规则组成的子集;
- 版本空间里的规则在训练集上表现相同,但对新样本可能给出不同判断(图 1.2 的 3 条规则对"(青绿,蜷缩,沉闷)"判法不一)→ 必须有归纳偏好选一条,才得到**最终模型**。

<span style="color:#2980b9">**层级关系**</span>

```
属性空间(27 个瓜)                   ← 样本所在的空间
   ↓ 每个假设 = 一个规则 = 一个好瓜集合
假设空间(65 条规则)                 ← 所有可能的学习结果
   ↓ 搜索:删除与正例不一致、与反例一致的规则
版本空间(3 条规则)                  ← 与训练集一致的候选规则集
   ↓ 归纳偏好(1.4 节)
最终模型(1 条规则)                  ← 学习算法的输出
```

<span style="color:#e67e22">**一句话记忆:假设空间 = 所有可能的判别规则;版本空间 = 经训练集淘汰后剩下的规则(候选);归纳偏好从候选中选出最终模型。**</span>

## 1.4 归纳偏好 (pp.6–9)

### 为什么必须有偏好

- 版本空间中的假设在训练集上等效,但对新样本可能给出不同输出。例如对新瓜"(色泽=青绿;根蒂=蜷缩;敲声=沉闷)":假设 ① 判为好瓜,假设 ②③ 判为坏瓜。
- **归纳偏好** (inductive bias):机器学习算法在学习过程中对某种类型假设的偏好(如"尽可能特殊"或"尽可能一般")。
- 任何**有效的**机器学习算法必有其归纳偏好;否则它会被训练集上"等效"的假设迷惑,无法产生确定结果(每次随机抽选等效假设,预测结果毫无意义)。
  - 例:"尽可能特殊"(适用情形尽可能少)→ 选假设 ③;"尽可能一般"且更相信根蒂 → 选假设 ①。⚠️ 对根蒂的"相信"不是基于训练样本的特征选择,而是基于领域知识的偏好(特征选择见第 11 章)。
- 回归视角(图 1.3):与有限训练样本点一致的曲线有无穷多条,算法必须有偏好才能选出一条(如偏好"平滑"的曲线 A 而非"崎岖"的 B)。

### 奥卡姆剃刀 (Occam's razor)

- **若有多个假设与观察一致,则选最简单的那个**——常用的、自然科学中最基本的原则(如认为"更平滑"= "更简单",则偏好曲线 A)。
- 但奥卡姆剃刀**并非唯一可行原则**,且其本身存在不同诠释:如假设 ① 与 ③ 哪个"更简单"并不显然,需借助其他机制解决。
- 归纳偏好 = 算法对"什么样的模型更好"的假设;该假设是否与问题本身匹配,大多时候直接决定算法能否取得好性能。

### 没有免费的午餐定理 (NFL)

- 直觉:图 1.4(a) 中 A 泛化能力比 B 强,但图 1.4(b) 显示存在 B 比 A 好的情况。
- 形式化(离散情形,令 $\mathbb{I}(\cdot)$ 为指示函数):
  - 算法 $\mathfrak{L}_a$ 基于训练集 $X$ 产生假设 $h$ 的概率为 $P(h\mid X,\mathfrak{L}_a)$;真实目标函数为 $f$。训练集外误差:
  $$E_{ote}(\mathfrak{L}_a\mid X,f)=\sum_{h}\sum_{\mathbf{x}\in\mathcal{X}-X}P(\mathbf{x})\,\mathbb{I}(h(\mathbf{x})\neq f(\mathbf{x}))\,P(h\mid X,\mathfrak{L}_a) \tag{1.1}$$
  - 考虑二分类且 $f$ 可为 $\mathcal{X}\to\{0,1\}$ 的任意函数;对**所有可能的 $f$ 按均匀分布**求和:对任意固定的 $h(\mathbf{x})$,恰有一半的 $f$ 与之不一致($\sum_f\mathbb{I}(h(\mathbf{x})\neq f(\mathbf{x}))=\frac{1}{2}2^{|\mathcal{X}|}$),故:
  $$\sum_f E_{ote}(\mathfrak{L}_a\mid X,f)=2^{|\mathcal{X}|-1}\sum_{\mathbf{x}\in\mathcal{X}-X}P(\mathbf{x}) \tag{1.2}$$
  结果**与学习算法无关**。即对任意两个算法 $\mathfrak{L}_a,\mathfrak{L}_b$:
  $$\sum_f E_{ote}(\mathfrak{L}_a\mid X,f)=\sum_f E_{ote}(\mathfrak{L}_b\mid X,f) \tag{1.3}$$
- 含义:无论算法多聪明或多笨拙(哪怕随机胡猜),在所有潜在问题上按均匀分布平均,期望性能相同。
- **重要前提**:所有"问题"出现机会相同/同等重要——现实并不如此,我们通常只关心自己正在解决的问题。
- **寓意**:脱离具体问题空谈"什么学习算法更好"毫无意义;要谈相对优劣必须针对具体学习问题,算法的归纳偏好与问题是否相配起决定性作用。

## 1.5 发展历程 (pp.10–13)

### 三阶段:推理期 → 知识期 → 学习期

| 时期 | 时间 | 核心思想 | 代表性工作 | 局限 |
|------|------|----------|------------|------|
| 推理期 | 1950s–70s 初 | 赋予机器逻辑推理能力即智能 | Newell & Simon"逻辑理论家"(证明《数学原理》52 条定理)、"通用问题求解"(获 1975 图灵奖) | 仅有推理能力远不够 |
| 知识期 | 1970s 中期起 | 使机器拥有知识 | Feigenbaum 等倡导专家系统(世界第一个 DENDRAL;"知识工程"之父,1994 图灵奖) | **知识工程瓶颈**:人把知识总结出来教给计算机太难 |
| 学习期 | 1980s 起 | 让机器自己学知识 | 1980 夏第一届机器学习研讨会 (IWML);1986 期刊 *Machine Learning* 创刊;1989 *Artificial Intelligence* 专辑 | — |

### 学习方式的经典分类(Cohen & Feigenbaum)

**机械学习**(死记硬背式:存储检索,非真正学习)、**示教学习**、**类比学习**、**归纳学习**(=从样例中学习,涵盖监督/无监督,八十年代以来被研究最多、应用最广)。

### "从样例中学习"的主流技术演进(四条主线)

1. **符号主义学习**(1980s 主流):决策树(以信息论为基础,以信息熵最小化为目标,第 4 章)、归纳逻辑程序设计 ILP(一阶逻辑表示,第 15 章;表示能力太强→假设空间太大,90 年代中期后陷入低潮)。
2. **连接主义学习**(神经网络):感知机 (Rosenblatt)、Adaline (Widrow);1983 Hopfield 求解旅行商问题、1986 Rumelhart 重新发明 **BP 算法**(第 5 章)使其复兴。缺点:黑箱模型、**试错性**(参数多、调参缺理论指导)。
3. **统计学习**(1990s 中期起主流):支持向量机 SVM 与核方法(第 6 章)。基础早在上世纪 60–70 年代奠定:Vapnik 1963 提出支持向量概念、1968 与 Chervonenkis 提出 VC 维、1974 结构风险最小化;90 年代中期才成主流(有效算法 + 连接主义局限凸显)。
4. **深度学习**(21 世纪初卷土重来):狭义 = "很多层"的神经网络(第 5.6 节)。走红两大原因:**数据大了、计算能力强了**(模型参数多,样本少易过拟合[第 2 章];复杂模型需强力计算)。缺乏严格理论基础,但显著降低应用门槛。

> 小故事:1952 年 Arthur Samuel 研制西洋跳棋自学程序(实际用了强化学习[第 16 章]),1959 年发表;1956 年在达特茅斯会议上报告,"机器学习"一词由此而来——定义为"**不显式编程地赋予计算机能力的研究领域**"。

## 1.6 应用现状 (pp.13–16)

- **大背景**:过去二十年人类收集、存储、传输、处理数据能力飞速提升,积累大量数据亟需分析利用 → 机器学习顺应需求成为热点。
- **计算机科学内部**:多媒体、图形学、网络通信、软件工程、体系结构、芯片设计都有其身影;计算机视觉、自然语言处理等应用技术领域,机器学习是最重要的技术进步源泉之一。
- **交叉学科**:生物信息学(基因组计划、基因药物)的数据分析环节;科学研究范式从"理论+实验"走向"理论+实验+计算",乃至"数据科学"——其核心正是通过分析数据获得价值。
- **标志性事件**:2001 NASA-JPL 科学家在 *Science* 撰文指出机器学习对科学研究的支撑作用;2003 DARPA 启动 PAL 计划(上升到国家安全高度);2006 卡耐基梅隆大学成立世界上第一个机器学习系(T. Mitchell 任首任系主任);2012 美国"大数据研究与发展计划"(大数据三大关键技术:机器学习=数据分析、云计算=数据处理、众包=数据标注)。

### 习题 1.2 详解:析合范式的假设计数(2026-08-08 补充)

**题目**:用最多含 $k$ 个合取式的析合范式表达西瓜分类问题的假设空间,估算共有多少种可能的假设。提示:注意冗余,如 $(A=\alpha)\vee(A=*)$ 与 $(A=*)$ 等价。

#### ① 组合模型:假设 = 样本空间子集,合取式 = 盒子

- **语义层**:一个假设 = 一个"好瓜集合" = 样本空间的一个子集。(不同语法可表示同一子集——这就是"冗余")
- **语法层**:合取式在每个属性上只有两种选择:取某个**具体值**或取通配符 `*` → 恰好对应网格中的**盒子**(点/线/面/体);析合 = 盒子并集。⚠️ 盒子在每维必须是"单点或全域",不能是任意区间 → 一行内不相邻的两个点**无法**并入一个合取式(这是本模型最重要的约束)。
- 盒子四类(属性取值 3、3、3 口径):体(3 个 `*`)1 个、面(2 个 `*`)9 个、线(1 个 `*`)27 个、点(0 个 `*`)27 个,共 $4^3=64$ 个。
- $k$ 无限制时:任意子集 = 若干单点盒子的并 → 全部 $2^{27}$ 个假设均可表示(上限)。

#### ② 精确计数(前向标记法精确枚举,含空假设 ∅)

> 方法:从空集开始逐层添加盒子 $T_k=\{s\cup b:s\in T_{k-1},b\in\text{盒子}\}$,去重后计数(⚠️ 注意:不能用"最少盒子数"递推 dp,剩余部分允许与已选盒子重叠)。

| $k$(最多 $k$ 个合取式) | 口径 B:属性全集 $3\times3\times3$ | 口径 A:表 1.1 实际取值 $2\times3\times3$ |
|---|---|---|
| 1 | 65 | 49 |
| 2 | 1,802 | 898 |
| 3 | 28,667 | 8,386 |
| 4 | 284,033 | 41,743 |
| 5 | 1,844,066 | 115,822 |
| 6 | 8,159,771 | 201,304 |
| 7 | 25,303,583 | 248,854 |
| 8 | 55,819,361 | 260,788 |
| 9 | 90,515,696 | **262,144 = $2^{18}$(饱和)** |
| 18 | **134,217,728 = $2^{27}$(饱和)** | — |

#### ③ 饱和点(可构造性证明,无需枚举)

- 把样本按"根蒂×敲声"分成 $3\times3=9$ 列,每列是**一个盒子**(色泽=*)。
- **口径 A(每列 2 个色泽点)**:任意子集按列覆盖,每列最多 1 个盒子 → 任意子集 $\le 9$ 个盒子;且"每列恰 2 点"的子集无法更少(2 点若并入盒子必含第 3 点)→ $k=9$ 时全部 $2^{18}$ 可达。
- **口径 B(每列 3 个色泽点)**:列内"2 点"无法用 1 个盒子覆盖(最小盒子是整列 3 点),每列最坏需 2 个盒子 → 上界 18;取"每列恰 2 点"的子集(共 18 点),跨列盒子(面/体)都会多包含点,唯一覆盖是 18 个单点 → 下界 18。故 $k=18$ 时全部 $2^{27}$ 可达。

#### ④ 手算示范($k=1$、$k=2$ 的组合思想)

- $k=1$:单盒子,恰 $4^3=64$ 种(+∅ 共 65)。
- $k=2$:无序对 $\binom{64}{2}=2016$;去掉包含关系(否则并集已在 $k=1$ 计过):体含 63 对、每个面含 $15\times9$、每条线含 $3\times27$ → $2016-(63+135+81)=1737$ 对;数值验证这 1737 对并集恰好两两不同 → 累计 $65+1737=1802$,与枚举一致。这就是题目说"估算"的原因:**$k\ge3$ 后无简单闭式,需枚举或容斥**。

#### ⑤ 口径说明(为什么网上答案五花八门)

1. **属性取值数**:2、3、3(仅表 1.1 出现的取值)还是 3、3、3(属性全集,与官方勘误一致)⚠️ 推荐后者;
2. **数什么**:数"不同假设(子集)"(本题语义)还是数"不同语法形式"——网上常见表如 48、931、10332… 是**非冗余表示形式数**(同一子集可有多个极小覆盖),远大于子集数;
3. **是否含空假设 ∅**(好瓜不存在)。

答题建议:写清盒子模型 + 饱和点构造 + 枚举表,即完整的"估算"。

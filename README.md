# ml-theory

周志华《机器学习》（西瓜书）读书笔记与课后习题。Goodfellow《深度学习》（花书）作工具书查阅。

## 仓库里有什么

```
notes/          章节笔记与习题解答
data/           习题用到的数据集
exercises/      可运行脚本与训练曲线
```

教材 PDF 因版权不入库。
